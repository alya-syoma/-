# Світло • Кривий Ріг

Невеликий застосунок з графіком відключень світла для **Кривого Рогу** з віджетом на
робочий стіл — як у «Київ Цифровий»: «Немає світла до 20:00 · вул. …, 5».

- Обираєте **вулицю та будинок** → черга (напр. 3.1) визначається автоматично з сайту ДТЕК.
- Віджет показує, чи є зараз світло і до котрої години, плюс наступне відключення.
- Великий віджет / екран застосунку показує смугу графіка на сьогодні й завтра.
- Якщо інтернету немає, показуються останні збережені дані.

| Стан | Що пише віджет |
|---|---|
| Світла немає | **Немає світла до 20:00** · Далі: 23:00–24:00 |
| Світло є | **Світло є до 16:30** · Відключення 16:30–20:00 |
| Точного графіка ще нема | **Світло є** · Можливе відкл. завтра з 03:30 |

## 📱 iPhone

Для iPhone використовується безкоштовний застосунок **Scriptable** — він дозволяє ставити
власні віджети без App Store і Mac.

1. Встановіть [Scriptable](https://apps.apple.com/app/scriptable/id1405459188).
2. Відкрийте файл [`ios/SvitloKR.js`](ios/SvitloKR.js) → кнопка «Copy raw file».
3. У Scriptable натисніть **+**, вставте текст, назвіть скрипт «Світло КР».
4. Натисніть ▶︎ → **Змінити адресу** → введіть частину назви вулиці → оберіть будинок.
5. На робочому столі: утримуйте палець → **+** → Scriptable → малий або середній віджет →
   «Додати». Потім утримуйте віджет → **Редагувати віджет** → Script: **Світло КР**.

Також працює на екрані блокування (віджети Scriptable «Inline / Circular / Rectangular»).

## 🤖 Android

1. Відкрийте на телефоні сторінку
   **Releases → [svitlo-kr-latest](../../releases/tag/svitlo-kr-latest)** цього репозиторію
   і завантажте `SvitloKR.apk`.
2. Відкрийте файл, дозвольте встановлення з цього джерела.
3. Запустіть «Світло КР», введіть вулицю, оберіть будинок.
4. Утримуйте палець на робочому столі → **Віджети** → «Світло КР» (малий 2×2 або з графіком 4×2).

APK збирається автоматично GitHub Actions (`.github/workflows/svitlo-android.yml`) при кожній
зміні в `svitlo-kr/android/`. Можна зібрати й локально в Android Studio (відкрити папку `android`).

## Звідки дані

- **Черга за адресою** — з офіційного сайту
  [ДТЕК Дніпровські електромережі](https://www.dtek-dnem.com.ua/ua/shutdowns).
  Застосунок відкриває цей сайт у вбудованому браузері й робить той самий запит, що й форма
  «Перевірити адресу» (`getStreets`, `getHomeNum`). Якщо сайт попросить перевірку «я не робот»,
  її треба пройти один раз.
- **Графік** — з відкритого репозиторію
  [Baskerville42/outage-data-ua](https://github.com/Baskerville42/outage-data-ua)
  (`data/dnipro.json` — Дніпро та область, включно з Кривим Рогом), який постійно копіює
  графіки ДТЕК. Оновлюється кожні ~15 хв.
- Якщо адресу не вдалося знайти — можна **обрати чергу вручну**.

> Це неофіційний застосунок. Остаточна інформація — на сайті ДТЕК.

## Структура

```
svitlo-kr/
├── ios/SvitloKR.js          # iPhone: скрипт для Scriptable (віджет + вибір адреси)
└── android/                 # Android: Kotlin, без сторонніх бібліотек (крім WorkManager)
    └── app/src/main/java/ua/svitlo/kr/
        ├── Schedule.kt      # логіка графіка (та сама, що в SvitloKR.js)
        ├── DataRepo.kt      # завантаження/кеш графіка, налаштування
        ├── AddressActivity.kt  # пошук черги за адресою через сайт ДТЕК
        ├── MainActivity.kt  # екран з графіком на сьогодні/завтра
        ├── OutageWidget.kt  # віджети + фонове оновлення
        └── BarRenderer.kt   # кольорова смуга 24 год
```
